One pickup line, at most 200 characters, as if a vending machine were flirting with a passing human, for the [make.fun competition](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## Entry

> I have forty snacks behind one little window, and you're the first person today who looked through it instead of at it.

Run with Node 22: `node main.ts` writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`).

## Craft

Spoken by the machine itself, built from its own world (snacks, the little window), turn in the last words, charming rather than creepy. Saturated angles avoided: "press my buttons", exact change, coil that won't drop / stuck snack, slot codes, "dropped your snack on purpose".
